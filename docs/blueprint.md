# **App Name**: IPOP

## Core Features:

- IPO Listing: Display a list of upcoming IPOs with key details.
- Prediction Score: Display an AI-driven score for each IPO, indicating its potential performance using data analysis tools.
- Probability Indicator: Show a probability percentage of the IPO being successful, calculated by the AI model.
- Expected Return: Calculate and display the expected percentage return based on the AI's analysis.
- User Authentication: Secure user login via Firebase Auth with email and Google authentication.
- IPO Details & SHAP: Detailed view of IPO data with SHAP explanation panel to understand contributing factors of the prediction.
- Data Ingestion: Automated data ingestion triggered on a schedule via Cloud Function to update IPO information. Connect to 3rd party API using tools and update the models in response.

## Style Guidelines:

- Primary color: Deep purple (#673AB7) to evoke a sense of sophistication and trust in financial analysis.
- Background color: Light grey (#F5F5F5) for a clean and modern look.
- Accent color: Teal (#00BCD4) to highlight key metrics and call-to-action buttons.
- Headline font: 'Space Grotesk' sans-serif for a techy, scientific feel; body font: 'Inter' sans-serif.
- Use crisp, modern icons to represent IPO data and metrics.
- Clean and structured layout with clear sections for IPO listings, predictions, and details.
- Subtle transitions and animations to enhance user experience when navigating between IPO details.
